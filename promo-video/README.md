# SabakHub — промо-ролик

78 секунд, 1920×1080, 30 fps. Ролик собран в Remotion, саундтрек синтезирован с нуля, поэтому прав на музыку не нужно.

## Как всё синхронизировано

Музыка идёт в темпе 120 BPM:

- 1 доля = 15 кадров;
- 1 такт = 60 кадров = 2 секунды.

Каждая сцена в `src/Promo.tsx` (`CUTS`) начинается на сильную долю. Анимации внутри сцен (появление уроков, карточек, сообщений) стоят на долях и восьмых через `beat(n)` из `src/theme.ts`.

| Такты | Секунды | Сцена | Музыка |
|---|---|---|---|
| 0–3 | 0–8 | Интро «сотни мелочей» | пэд + арпеджио |
| 4–5 | 8–12 | Логотип | удар, полутемп |
| 6–7 | 12–16 | Все модули | бочка, райзер |
| 8–11 | 16–24 | Расписание + конфликт | **дроп** |
| 12–15 | 24–32 | Кабинеты и свободные окна | дроп |
| 16–19 | 32–40 | Филиалы | дроп |
| 20–23 | 40–48 | Telegram-бот с ИИ | брейкдаун |
| 24–27 | 48–56 | AI-ассистент | **второй дроп** + мелодия |
| 28–31 | 56–64 | Аналитика | дроп |
| 32–33 | 64–68 | Монтаж модулей (по доле) | райзер |
| 34–38 | 68–78 | Финал + CTA | удар, хвост |

## Ролик 2 — «SabakHub для владельца»

62 секунды, 1920×1080, **60 fps**. При 120 BPM одна доля — 30 кадров, один такт — 120. Кадры рендерятся в PNG, видео кодируется с CRF 14, чтобы мелкий текст интерфейса оставался чётким.

- Код: `src/owner/`. Композиция — `SabakHubOwner`, трек — `music/make_owner_track.py` → `public/music-owner.wav`.
- Все тайминги звуков интерфейса (клики, штамп «Утверждено», звук WhatsApp, монеты, «блипы» при переносе) лежат в одном файле, `src/owner/cues.json`. Его читают и трек, и сцены. Если сдвинуть событие там, сдвинутся и звук, и картинка.

| Такты | Секунды | Сцена |
|---|---|---|
| 0–1 | 0–4 | 4 вопроса владельца (смена кадра каждые 2 доли) |
| 2 | 4–6 | Логотип, «Все ответы — на одном экране» |
| 3–6 | 6–14 | Финансы: Обзор → Движение средств → Расходы по категориям → Прибыльность курсов |
| 7–12 | 14–26 | Зарплата: ставки → окно «Ставка преподавателя» с формулой → ведомость → Утвердить → Выплатить |
| 13–16 | 26–34 | Напоминания: график, WhatsApp, Telegram, «Оплачено» |
| 17–20 | 34–42 | Контроль: KPI учителей, AI-анализ оттока, сводка в Telegram, роль «Кассир» |
| 21–25 | 42–52 | Переезд: файлы → таблица → строки улетают в SabakHub |
| 26–30 | 52–62 | Итог и призыв к действию |

```bash
python -I music/make_owner_track.py public/music-owner.wav
npx remotion render src/index.ts SabakHubOwner out/sabakhub-owner.mp4 --image-format=png --crf=14 --x264-preset=slow
```

### Версия для Instagram Reels

1080×1920, 60 fps. Код — `src/owner/reels/`, композиция `SabakHubOwnerReels`, обложка — still `SabakHubOwnerReelsCover`. Трек, `cues.json` и тайминги сцен те же, что у горизонтальной версии. Раскладки пересобраны под вертикаль, данные (имена, цифры) импортируются из горизонтальных сцен.

Всё, что нужно прочитать, лежит в колонке 900 px между y≈340 и y≈1500. Сверху ~220 px занимает шапка Instagram, снизу ~380 px — подпись к посту, справа ~120 px — кнопки (лайк, комментарий, «поделиться»). Посмотреть эти зоны можно поверх кадров:

```bash
npx remotion bundle --out-dir=build
COMP=SabakHubOwnerReels PROPS='{"guides":true}' node stills.mjs 450 1290 2730
npx remotion render src/index.ts SabakHubOwnerReels out/sabakhub-owner-reels.mp4 --image-format=png --crf=14 --x264-preset=slow
npx remotion still src/index.ts SabakHubOwnerReelsCover out/sabakhub-owner-reels-cover.png
```

## Ролик 3 — «SabakHub в телефоне» (концепт мобильного приложения)

62 секунды, 1920×1080, **60 fps**, 120 BPM, но ударные играют в полутемпе (клэп на третью долю), поэтому ролик ощущается спокойным, а склейки по-прежнему ложатся на двухсекундные такты. Один макет смартфона справа, внутри него перелистываются экраны модулей; слева — подписи. Каждый кадр держится 3–4 секунды.

- Код: `src/mobile/` (`kit.tsx` — подписи и раскладка, `phone.tsx` — корпус, статус-бар, таб-бар и переходы между экранами, `screens/` — экраны модулей). Композиция — `SabakHubMobile`.
- Трек — `music/make_mobile_track.py` → `public/music-mobile.wav`. Секции и все звуки интерфейса (клики, «слушаю», поп-ы оценок, пуш, WhatsApp, монета, штамп) — в `src/mobile/cues.json`; его читают и трек, и сцены.
- Модули взяты из графа Obsidian (`Проекты/SabakHub модули`): порядок и тексты подписей — по заметке `SabakHub.md`, раздел «Самое сильное для продажи».

| Такты | Секунды | Сцена |
|---|---|---|
| 0–1 | 0–4 | Лок-скрин, телефон поднимается, уведомление, запуск приложения |
| 2–3 | 4–8 | Главный экран: сегодня, «сейчас идёт», быстрые действия |
| 4–7 | 8–16 | Журнал: лист группы → микрофон → «Всем по пять…» → ИИ проставляет оценки |
| 8–10 | 16–22 | Расписание: день филиала, свободные кабинеты → перенос занятия → пуш преподавателю |
| 11–14 | 22–30 | Финансы: должники → напоминание в WhatsApp родителю → «Оплачено» |
| 15–16 | 30–34 | Зарплата: формула преподавателя строится по строкам, итог |
| 17–19 | 34–40 | Экзамен: кольцо 84 %, темы, ИИ-отчёт печатается |
| 20–21 | 40–44 | KPI преподавателей |
| 22–23 | 44–48 | Карточка ученика (филиал, курс, преподаватель, кабинет, оплата) |
| 24–25 | 48–52 | Олимпиада: жюри ставит баллы, «Оценено» (модуль в разработке) |
| 26–27 | 52–56 | Монтаж: три телефона |
| 28–30 | 56–62 | Логотип, слоган, «скоро в App Store и Google Play» |

```bash
python -I music/make_mobile_track.py public/music-mobile.wav
npx remotion render src/index.ts SabakHubMobile out/sabakhub-mobile.mp4 --image-format=png --crf=14 --x264-preset=slow
npx remotion bundle --out-dir=build && COMP=SabakHubMobile OUTDIR=out/mobile-qa node stills.mjs 760 1200 1700   # кадры для проверки
```

## Команды

```bash
npm install
python -I music/make_track.py public/music.wav   # пересобрать трек
npm run studio                                  # превью в браузере
npm run render                                  # out/sabakhub-promo.mp4
```

Чтобы поставить свою (лицензионную) музыку, положите её в `public/music.wav`. Трек должен быть в 120 BPM, а первая сильная доля — на 0:00. Иначе склейки разойдутся с битом.
